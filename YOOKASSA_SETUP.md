# ЮKassa — подключение тестового магазина

1. В личном кабинете ЮKassa создайте тестовый магазин.
2. В админке программы откройте **Оплата** → выберите **ЮKassa**.
3. Вставьте тестовые **Shop ID** и **Secret Key**.
4. Оставьте API URL `https://api.yookassa.ru/v3`.
5. Для первого теста выберите **Банковская карта** или **Платёжная страница ЮKassa**.
6. Нажмите **Проверить подключение**, затем **Сохранить**.
7. Return URL можно оставить пустым: программа сформирует `/payment-result?order_id=...` сама.
8. Для webhook в кабинете ЮKassa укажите публичный HTTPS URL `/api/payments/yookassa/webhook`. Локальный `:5000` из интернета недоступен, поэтому для локального теста дополнительно используется серверная проверка статуса после возврата и кнопка «Проверить оплату».

## Тестовая карта
Для успешного теста можно использовать, например, Mastercard `5555 5555 5555 4477`; срок действия — любая будущая дата, CVC и код 3-D Secure — любые числа.

## Бронь
- корзина: 3 минуты;
- после начала онлайн-оплаты: по умолчанию 10 минут (изменяется в админке);
- если платёж придёт позже и товар уже закончился, для ЮKassa программа пытается автоматически сделать полный возврат; если возврат не удался, статус становится `refund_required`.

## СБП
Код `sbp` предусмотрен в настройках для боевого магазина. В тестовом магазине ЮKassa основная проверка проводится картой/ЮMoney; не считайте отсутствие тестового СБП ошибкой программы.
