ЮKassa

В тестовом магазине ЮKassa используйте тестовый Shop ID и Secret Key. Тестовая среда определяется самими ключами — отдельного API URL не требуется.
Для webhook нужен публично доступный HTTPS-адрес. Для локального теста программа также умеет проверить статус через API после возврата со страницы оплаты.

Сбер

Если реальный шлюз выключен — работает встроенный demo-режим. Для ЮKassa сначала можно подключить тестовый магазин.
