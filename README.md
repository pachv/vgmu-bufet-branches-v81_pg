# ВГМУ Буфет — филиалы + WebSocket + таймер выдачи

## Запуск

```bash
pip install -r requirements.txt
python app.py
```

## Адреса

Клиент: http://127.0.0.1:5000  
Оператор: https://127.0.0.1:5000/operator-login  
Админка: http://127.0.0.1:5000/admin  

## Пароли

Админ: `admin123`

Повара:
- `podval / 1234` — Буфет в подвале
- `floor1 / 1234` — Буфет на 1-ом этаже
- `floor2 / 1234` — Буфет на 2-ом этаже

## Что исправлено в v2

- В админке пользователи снова кликаются.
- Клиенты видят остатки блюда по всем буфетам.
- Клиент не может добавить в корзину больше, чем есть в выбранном буфете.
- Заказ нельзя создать без входа по телефону.
- Повар не может принять заказ, если позиции уже закончились в его буфете.
- После статуса «Готов к выдаче» включается таймер 1.5 часа.
- Если заказ не забрали за 1.5 часа:
  - статус становится «Время получения истекло»;
  - позиции возвращаются в остатки выбранного буфета;
  - заказ исчезает с кухни;
  - клиент и админ видят статус expired.
- Обновления идут через Flask-SocketIO, не через частый polling.


## Исправлено в v3

## v81 — планшетные оповещения оператора

- При открытии операторской появляется обязательный экран «Начать смену». Одно нажатие выполняется в пользовательском жесте и разблокирует звук в мобильном Chrome.
- Используются два независимых механизма звука: `/static/alarm.wav` и Web Audio API как fallback.
- Новый заказ даёт серию из трёх сигналов, вибрацию и системное уведомление.
- Для мобильных уведомлений используется `ServiceWorkerRegistration.showNotification()`, а не `new Notification()`.
- Добавлен Screen Wake Lock: во время смены планшет не должен сам гасить экран; после возврата на вкладку wake lock запрашивается повторно.
- Добавлена кнопка «Проверить звук».
- Service Worker переведён на scope `/`, добавлен `notificationclick`, чтобы по уведомлению возвращаться в операторскую.
- Permissions-Policy разрешает same-origin autoplay и screen-wake-lock.
- Мобильная и ПК-версии операторской используют одну и ту же логику; overlay адаптирован под планшет/телефон.
